# SmartBuild Mini — Frontend (React + Vite)

Modern, responsive construction material management web application.

## Deploying to Vercel

1. Import the repository `https://github.com/santhoshinipatel22/TT_frontend.git` into [Vercel](https://vercel.com).
2. Framework Preset: **Vite**
3. Root Directory: `./` (or leave default)
4. Build Command: `npm run build`
5. Output Directory: `dist`
6. **Environment Variables on Vercel**:
   - `VITE_API_BASE_URL`: The URL of your deployed Render backend (e.g., `https://smartbuild-backend.onrender.com/api`)
7. Click **Deploy**.
